# 🎨 BEYONDLINES - Website Design Guidelines

> *Visual & UX Design for Landing Website*

---

## **Design Philosophy**

### **Core Values**
- **Authentic**: Real, human-centered design
- **Intelligent**: Smart but not intimidating
- **Bold**: Confident, rebellious energy
- **Clean**: Minimal, focused, clear

### **Target Audience Psychology**
- **Creators**: Want more time, less stress
- **Businesses**: Need results, not features
- **Agencies**: Value efficiency and scale
- **Tech-savvy**: Appreciate smart design

---

## **Visual Identity**

### **Color Palette**
```
Primary: #000000          # Bold Black
Secondary: #FFFFFF        # Clean White
Accent: #FF6B35         # Rebel Orange
Support: #00D4AA         # Success Green
Warning: #FFD23F         # Attention Yellow
Error: #FF4757          # Alert Red
```

### **Typography**
```
Headings: 'Inter' or 'Space Grotesk' (Bold, 700)
Body: 'Inter' (Regular, 400)
Mono: 'JetBrains Mono' (for code/tech elements)

Sizes:
H1: 3.5rem (56px) - Hero headlines
H2: 2.5rem (40px) - Section headers
H3: 1.875rem (30px) - Sub-section headers
Body: 1.125rem (18px) - Main content
Small: 0.875rem (14px) - Meta info
```

### **Logo & Mark**
```
Logo: "BEYONDLINES" in custom typeface
Tagline: "Where AI meets authenticity"
Mark: Simple geometric "B" with rebel orange accent
Favicon: Minimal "B" mark
```

---

## **Layout Structure**

### **Mobile-First Grid**
```
Container: 1200px max-width
Gutter: 2rem (32px)
Columns: 12-column grid
Breakpoints:
- Mobile: 0-768px
- Tablet: 768-1024px
- Desktop: 1024px+
```

### **Section Spacing**
```
Hero: 100vh minimum
Sections: 6rem (96px) vertical padding
Cards: 2rem (32px) internal padding
CTAs: 1.5rem (24px) padding minimum
```

---

## **Component Design System**

### **Buttons**
```
Primary: Black background, white text
- Hover: Rebel orange (#FF6B35)
- Padding: 1rem 2rem
- Border-radius: 8px
- Font-weight: 600

Secondary: White background, black text
- Hover: Light grey (#F5F5F5)
- Border: 2px solid black
- Same padding/radius

Ghost: Transparent background, rebel orange text
- Hover: Light orange background
- Underline on hover
```

### **Navigation**
```
Desktop: Horizontal top nav
- Logo left
- Nav items center
- CTA right
- Sticky on scroll

Mobile: Hamburger menu
- Full-screen overlay
- Logo top-center
- Menu items stacked
```

### **Cards & Components**
```
Feature Cards:
- White background
- Black border (2px)
- Border-radius: 12px
- Padding: 2rem
- Hover: Subtle shadow
- Transition: 0.3s ease

Testimonials:
- Large quote icon
- Person image (circular)
- Bold name, light title
- 5-star rating
```

## **Typography Hierarchy**

### **Headline Strategy**
```
Hero H1: 3-4 words, bold impact
Section H2: Benefit-driven questions
Feature H3: Feature names, bold
Card Titles: Short, scannable
```

### **Content Principles**
```
- One idea per paragraph
- Use rebels/energetic language
- Avoid technical jargon
- Focus on benefits over features
- Use emojis sparingly (🚀 ⚡ 🎯)
```

```
Buttons: 0.3s ease transition
```

### **Loading States**

## **Mobile Considerations**

### **Responsive Behavior**
```
Navigation: Hamburger → Full screen
Hero: Single column, CTA stack
Features: Single card column
Testimonials: Carousel
Footer: Stacked layout
```

### **Touch Targets**
```
Minimum button size: 44px
Spacing between touchables: 8px
Easy thumb zone for mobile CTAs
Large tap areas for navigation
```

---

## **Accessibility Guidelines**

### **WCAG 2.1 AA Compliance**
```
Color Contrast: Minimum 4.5:1
Focus States: Visible outlines
Keyboard Navigation: Tab-friendly
Screen Readers: Proper ARIA labels
Motion: Respect prefers-reduced-motion
```

### **Text Accessibility**
```
Font sizes: Never below 14px
Line height: 1.5 for body text
Paragraph length: Max 80 characters
Alt text: All images described
```

---

## **Performance Requirements**

### **Loading Optimization**
```
Above fold: < 2 seconds
Interactive: < 3 seconds
Images: WebP format, lazy loaded
Fonts: Preload critical fonts
JavaScript: Minimize bundle size
```

### **Animation Performance**
```
Use transform/opacity for 60fps
Avoid layout thrashing
GPU-accelerated animations
Smooth scroll behavior
Reduce paint operations
```
