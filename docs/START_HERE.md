# 🎯 Prismind - Unified Dashboard

## Quick Start

**ONE COMMAND to start everything**:

```bash
python dashboard.py
```

Then open: **http://localhost:5000**

---

## What You Get

### 📊 Dashboard
- Overview of all stats
- Quick actions to review/schedule/analyze

### 📝 Review Posts
- Pull posts from your 673-post database
- Gemini generates rewrites (Russian/English routing)
- Edit in the browser (textarea)
- Approve → auto-schedules
- Reject → logs for learning

### 📅 Scheduled Posts
- See all scheduled posts
- Filter by platform (Threads/Twitter)
- Filter by language (Russian/English)
- View content, timing, priority

### 📈 Trends & Suggestions
- Analyzes your database posts
- Shows trending topics
- **Proactive suggestions**: "People discuss X, here's what YOU could say"
- Matches trends with YOUR opinions
- Filters out political/religious topics

---

## Full Workflow

1. **Open Dashboard**:
   ```bash
   python dashboard.py
   ```

2. **Go to "Review Posts" tab**:
   - Loads 5 posts from database
   - Generates rewrites automatically
   - You approve/edit/reject each one
   - Approved posts get scheduled

3. **Check "Scheduled" tab**:
   - See all posts ready to publish
   - Filter by platform/language

4. **Check "Trends" tab**:
   - See what's trending
   - Get content suggestions based on your opinions

---

## Language Routing

- **Threads → Russian**
- **Twitter → English**
- **Telegram → Russian**
- **Reddit → Russian** (rewritten for Threads)

Automatic. No configuration needed.
