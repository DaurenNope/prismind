🔧 TROUBLESHOOTING:

Problem: ModuleNotFoundError
Solution: ./start_bot.sh (handles PYTHONPATH automatically)

Problem: Still showing "Unknown • Unknown"
Solution:
    rm beyondlines.db
    ./start_bot.sh
    # Then /collect in Telegram

Problem: No new bookmarks collected
Solution:
    - Make sure you have NEW bookmarks on Twitter/Reddit
    - Check credentials in .env
    - Check logs: tail -f logs/telegram_bot.log

Problem: Bot won't start
Solution:
    - Check .env has TELEGRAM_BOT_TOKEN
    - Activate venv: source .venv311/bin/activate
    - Install deps: pip install -r requirements.txt
