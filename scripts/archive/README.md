# Scripts Archive

This directory contains archived scripts that are no longer actively used.

## Structure

- `one_time_fixes/` - Scripts that fixed specific issues (likely run once)
- `one_time_operations/` - Backfill and migration scripts (one-time operations)
- `old_tests/` - Obsolete test scripts replaced by newer versions

## When to Remove

These scripts are kept for reference but can be safely deleted if:
- The fixes/operations are confirmed complete
- No one references them anymore
- They're older than 6 months

## Active Scripts

Active scripts remain in the main categories:
- `collection/` - Active collection scripts
- `analysis/` - Active analysis scripts
- `publishing/` - Active publishing scripts
- `database/` - Active database operations
- `testing/` - Active test scripts
- `utilities/` - Active utility scripts
